🔴 Mi Pokédex en Python 🐍
¡Hola! Este es mi proyecto final. Hice una Pokédex que busca información real de Pokémon en internet y la guarda en tu computadora.

🛠️ ¿Qué hace?
Busca: Se conecta a PokeAPI para traer datos de cualquier Pokémon.

Muestra: Te da el peso, tamaño, habilidades, tipos y el link de su imagen.

Guarda: Crea una carpeta llamada pokedex y guarda la info en archivos .json.

📦 Requisitos
Necesitas instalar la librería requests:

Bash
pip install requests
🧠 ¿Qué aprendí?
Conectar Python con internet (APIs).

Manejar errores para que el programa no se trabe.

Crear carpetas y guardar archivos automáticamente.
